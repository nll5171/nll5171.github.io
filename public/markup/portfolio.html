Check out the repo here on GitHub!

If it wasn't obvious enough already, this project is the very website you're reading this on. Maybe a bit egotistical, but I think it's worth including here just so I can talk a bit about the process behind it.

This site was originally just a series of statically served HTML pages using Bootstrap for a front-end. Given that the purpose was just to showcase the things I've worked on, I figured it'd be fine to keep it simple and lazy for the purpose of getting things up quickly. For a while, I felt that way and didn't change anything, simply updating the site whenever I worked on something new.

As a student of RIT, this site was, for quite a while, hosted by them. Once I became an Alumn however, I was no longer given permission to host sites through them, and migrated to GitHub pages. It was also around this time that I decided to change up my implementation of the site to something a bit nicer. Having not yet learned the Vue framework, I decided this would be a quick an easy opportunity to learn it.

For the first time in my life, I was correct about this.

Having already learned Angular, Vue felt similar yet simpler, as to be expected. And given that the site wasn't particularly complex, with very few moving parts, I was able to migrate to Vue in no-time over the course of a weekend.

Were I to spend a bit more time on the project, I'm sure there's some other things I would adjust, namely how projects are currently loaded-in feels a bit sluggish and sloppy, but it's relatively low on my priority list.
