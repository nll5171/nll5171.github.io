Ignite-Boost.net

Check out the project here on GitHub!

Ignite-Boost.net was a MERN application serving as a replay database for the fighting game Dengeki Bunko Fighting Climax, and its update, Dengeki Bunko Fighting Climax: Ignition. It was developed by my friend Anthony Pichardo during his time as a student at RIT. Similarly to the Scavenger Hunt project on this site, Ignite-Boost was also created for the Rich Media Web Application Development II course.

He had expressed interest in remaking or redesigning it for quite a while, as the front-end was not responsive to mobile, and over time, a few other issues became apparent. Most notably, searching for matches from the first version of the game would yield no results, despite several thousand existing in the Mongo database itself. Were he to do so, he had planned to recreate it with an Angular front-end, so that he could better familiarize himself with the framework.

Since it had been a while and he became extremely busy with work and other hobbies, I figured it would be a great opportunity to redesign the site myself as a way of learning Angular, something I also wanted to do having spent most of my time with React. While the other notable fighitng game replay database, Replay Theater, uses a minimalist look, I wanted to try going for something specific to the game the site was designed for. Replicating the game's VS screen seemed like a good way to do this while keeping things intuitive, and so I geared my focus towards replicating it. That said, since the site would need to be adjusted for mobile devices, the VS screen design would be too small at those viewports, and I thus opted to replicate Replay Theater's layout in those cases.

Since I was looking to improve with my knowledge of front-end design, I also took the opportunity to learn Angular Material. I had hoped Material Design components would provide responsive, easy-to-integrate components to build off of. Generally speaking, they were. TailwindCSS, a CSS framework that had grown quite popular, had also caught my eye. Its method of styling by assigning named classes for each CSS property felt as though it would make styling easier to keep track of. And having finished this project, while I think I could see myself using Angular Material depending on the situation, TailwindCSS feels too good not to include in most projects.

In any case, this project took longer than I had anticipated to complete, being around three full months. That said, I'm more than happy with the outcome. I was able to capture my initial vision for the project and make something that feels responsive and intuitive while maintaing the visual identity of the game it exists for.
