CPS-3 ROM Conversion Tool Remake

Check out the project source here on GitHub!

This project is a remake of the CPS-3 ROM Conversion Tool I had built back in 2020, and if you're interested, I would definitely reccomend checking it out for the specifics of how the ROM conversion process is handled.

The goal with this particular project was to experiment with cross-platform desktop applications built using modern web frameworks such as Angular, Vue.js, and React.js. I wanted to see if it'd be useful for potential future projects down the line, and figured the logic was simple enough that I could make this pretty quickly.

I began by working with Neutralino.js, seeing that, unlike Electron or NW.js, it did not have to bundle Chromium, significantly reducing the bloat and potentially the startup time of the application. The API was simple to work with, and I was able to finish the project in no time at all.

Unfortunately, I soon found out that the API was quite slow when it came to file read/write operations, which, given that's all this project really does, made the tool feel pretty bad to use. To put things into perspective, the conversion process would take anywhere from 10~20 seconds, where it was essentially instant on the version I built in Java nearly six years ago.

I needed to find a different tool in its place, and that's when I came across Tauri. Tauri promised similarly small bundles compared to Electron and NW.js, but also high performance alongside it. I was able to integrate the front-end I had designed for the Neutralino build of the project with no trouble, and as I had hoped, it offered significantly higher performance on file read/write operations.

Unfortunately, it is still slower than the Java project, but not nearly enough to hamper the impact of using the tool I feel. Ultimately, I'm pretty happy with how things turned out. The project is functionally the same as it was nearly six years ago, but it's better programmed, now includes validation, and has a much nicer looking front-end built using React.js in tandem with TailwindCSS and daisyUI for easy styling and components.
