Throw Reject Miss in Under Night In-Birth

An in-depth code analysis on the throw reject miss mechanic in Under Night In-Birth, and how it changed between different versions of the game. In particular, the changes made between the Under Night In-Birth Exe:Late[cl-r] and Under Night In-Birth 2 Sys:Celes.

I'd recommend watching the video for a proper explanation of how this mechanic works but essentially, when you input a throw, you cannot tech throws for a limited period of time. The amount of time and situations where you would be unable to tech a throw changed between the aforementioned games.

Going more into the creation of this project, I would argue it was a middle ground between the last two in terms of how involved it was. Unlike with figuring out meter build, I did not need to analyze assembly code, but I did need to do quite a bit more code analysis than I did to understand what changed with the green shield mechanic. In the end however, the changes were quite simple, it just took me a bit to understand what they were and how everything fit together, given there were more moving parts to work with.

And unlike the previous two videos, I had decided that I would make the primary focus of this video to be the code analysis. Ideally, I explained things well enough that the code wasn't particularly difficult to figure out, but it's also pretty simple by itself. The difficulty only comes into the picture when it came to working backwards in figuring out how the system was implemented in the first place.
